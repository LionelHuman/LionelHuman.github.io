核心目录

目录 作用与说明
/bin 存放普通用户和 root 管理员都能使用的基础命令（如 ls, pwd 等）。
/etc 系统配置文件目录（重中之重）。几乎所有的软件安装后，都会把配置文件放在这里，比如 /etc/nginx、/etc/my.cnf。
/home 普通用户的家目录。比如创建一个叫 tom 的用户，他的家目录就是 /home/tom。
/root 超级管理员（root）的家目录（普通用户进不去）。
/var 存放变化的文件，特别是系统运行时的日志文件。比如 /var/log/messages 存放系统日志，排查错误经常用到。
/tmp 临时文件夹，重启后里面的内容会被清空。

认清终端提示符

终端符号 含义说明
root 当前登录的用户名（超级管理员）。
node1 这台服务器的主机名。
~ 当前所在的目录（~ 代表家目录，root 的家是 /root）。
# 代表超级管理员权限；普通用户则是 $。

基础导航

理解了目录结构，我们就可以学习怎么在目录之间“行走”和“查看”了

核心导航三剑客

命令 作用与说明
pwd 查看当前目录。当你不知道自己在哪个位置时，敲 pwd 秒懂。
ls 查看当前目录下有什么。
ls -a 查看所有文件，包括隐藏文件（以 . 开头的文件）。
ls -l (或直接 ll) 以列表形式显示文件的详细信息（权限、大小、修改时间）。
ls -lh 人性化显示文件大小（比如 10M、5K，而不是一串难懂的数字）。
cd 切换目录。
cd /etc 进入 /etc 目录。
cd ~ 回到当前用户的家目录（root 用户就是 /root）。
cd .. 回到上一层目录。
cd - 回到上一次所在的目录。

文件的增删改查与基础操作

文件的创建、复制、移动与删除

命令格式 作用与详细说明
touch 文件名 创建一个空文件。比如 touch main.py。
cp 源文件 目标路径 复制文件。如果复制文件夹，必须加 -r 参数（如 cp -r 文件夹/ 目标路径/）。
mv 源文件 目标路径 移动文件或文件夹（可以跨目录）。它还可以用来重命名，比如 mv a.txt b.txt 就将 a.txt 改名为了 b.txt。
rm 文件 删除文件。
rm -r 文件夹 递归删除文件夹。
rm -f 文件 强制删除（不提示确认）。

💣 致命警告：在 Linux 中 rm -rf / 是著名的“删库跑路”命令，千万不要在 root 权限下乱敲，否则你的整个操作系统会瞬间消失！

文件内容查看与搜索（排查日志必杀技）

命令格式 作用与详细说明
cat 文件名 一次性把文件所有内容打印到屏幕上（适合内容很少的配置文件）。
more 文件名 分页查看文件（按空格键翻页，按 q 退出）。
less 文件名 高级分页查看（强烈推荐！）。按 上下方向键 滚动；按 / 加关键词进行搜索；按 n 跳到下一个匹配结果。
head -n N 文件名 只看文件的前 N 行。例如 head -n 20 查看前 20 行。
tail -f 文件名 运维神器！ 动态查看文件的最后几行，一直保持滚动刷新。比如用 tail -f /var/log/messages 实时监控服务器新产生的日志。
wc 文件名 统计文件信息。
wc -l 文件名 统计文件共有多少行。
wc -w 文件名 统计文件共有多少单词。
grep "关键词" 文件名 在文件中搜索指定关键词，并高亮显示。
grep "关键词" -r 目录 实战：如 grep "Failed password" /var/log/secure。这条命令能从几十万行安全日志中，精准揪出是谁在暴力破解你的服务器密码！

编辑器的“神”：Vim 实用指南

Linux 服务器中，我们不能像在 Windows 里那样用鼠标点开记事本。Vim 是 Linux 下必学、必会的文本编辑器，被誉为“编辑器之神”。

认识 Vim 的三种模式

新手使用 Vim 最怕的就是不知道自己处于什么状态，打不出字

命令模式（默认）：刚用 vim 文件名 打开文件时，你就处于这个模式。此时按键盘上的键是控制光标、复制粘贴、删除，不是打字！

插入模式（编辑模式）：在命令模式下，按 i（光标前插入）或 a（光标后插入）进入。此时屏幕左下角会出现 – INSERT –，这时候你才能像写 Word 一样敲字。写完字，按 ESC 键退出插入模式，回到命令模式。

底行模式（末行模式）：在命令模式下按英文冒号 :，进入底行模式。此时左下角会出现 :，用于保存文件、退出编辑器、搜索替换。

高频必会的 Vim 快捷键

操作类型 快捷按键 作用说明
编辑 i / a / o 光标前插入 / 后插入 / 下一行插入
复制/删除 yy / dd / p 复制当前行 / 删除当前行 / 粘贴
跳转 gg / G 跳转到文件第一行 / 跳转到文件最后一行
撤销 u 撤销上一次操作（相当于 Windows 的 Ctrl+Z）
保存退出 :wq 保存并退出
首选保存 :x 运维首选。保存并退出。区别：如果文件未改动，:x 不会更新文件的最后修改时间，而 :wq 会。
强制退出 :q! 不保存，强行退出
开启行号 :set nu 在左侧显示行号（排查代码错误极有用）
取消高亮 :noh 搜索后，取消匹配到的关键词高亮

Vim 常见报错：交换文件 .swp 问题

如果你打开文件时，弹出了一大堆英文提示，不要慌！这是因为文件之前没保存就关机或断网了，系统自动生成了一个隐藏的备份文件（如 .文件.swp）。

恢复内容：按提示输入 R 恢复内容，然后 :wq 保存退出。

彻底删除：在命令行执行 rm .文件名称.swp，下次打开就不会有弹窗了

常用打包与压缩 tar

Linux 中常见的压缩包后缀是 .tar.gz

tar 命令组合 作用与说明
tar -czvf 压缩包名.tar.gz 文件或文件夹 压缩：创建一个使用 gzip 压缩的归档包。
tar -xzvf 压缩包名.tar.gz 解压：解压 gzip 压缩包到当前目录。
tar -xzvf 压缩包名.tar.gz -C /指定目录 解压到指定目录：解压 gzip 压缩包到指定的文件夹路径中。

tar 参数 参数含义

-v 显示执行过程（Verbose），能看到正在处理的文件名。
-f 指定归档文件/压缩包的名称。
-C 解压到指定目录（Change directory），后接绝对路径。

总结与学习建议

Linux 命令的学习没有捷径，核心就是“多敲、多用、多练”。

记重点，别背大全：把 ls、cd、cp、mv、rm、find、tar、grep、vim 这几个核心命令练熟，你已经能应付 80% 的工作了。

学会利用 –help 和 man：遇到陌生命令，敲 命令 –help 就能看到最简单的用法。

养成查日志的习惯：在遇到问题怀疑是服务器故障时，第一时间去 /var/log 下面看看日志，你会发现很多问题其实是有迹可循的。

🚀 进阶提示：等你熟练了这些基础命令，就可以开始尝试把它们组合起来，写成 Shell 脚本。相信过不了多久，你就能体会到一个命令自动搞定一整套环境部署的快乐了！

用户与用户组管理

Linux 是一个多用户、多任务的操作系统，安全权限体系基于用户和用户组

用户组管理（相关文件 /etc/group）

命令 作用与说明
groupadd 组名 添加组（示例：groupadd project_team）。
groupadd -g 2000 test 指定组 ID 为 2000 创建 test 组。
groupmod -n 新名 旧名 修改组名，将旧组名改为新组名。
groupdel 组名 删除指定的用户组。

用户管理（相关文件 /etc/passwd、/etc/shadow）

命令 作用与详细说明
useradd zhangsan 默认创建用户，同时生成同名的用户组，家目录在 /home/zhangsan。
useradd -g admins lisi 指定用户的主组为 admins。
useradd -G ops,dev wangwu 指定用户的附加组（附属组）。
useradd -u 2000 wangwu 指定该用户的 UID 编号。
useradd -r -s /sbin/nologin mysql 创建一个系统账号（通常用于运行 MySQL 等软件），并禁止该用户登录 Linux，提升安全性。
命令/提醒 作用与详细说明
passwd 用户名 超级管理员给用户重置密码，输入两次即可。
⚠️ 密码规则提醒 普通用户自己改密码，需要先输入当前旧密码。且新密码必须满足“大小写字母 + 数字 + 符号”的复杂度要求。
命令 作用与详细说明
usermod -g test lisi 把 lisi 的主组改成 test。
usermod -md /home/newhome zhaoliu “搬家”：把 zhaoliu 的家目录移到新位置，并把原来的文件（家具）一并搬过去。
usermod -s /sbin/nologin wangwu 禁用 wangwu 账号的登录权限。
usermod -L 用户名 / usermod -U 用户名 锁定 / 解锁 账号。
命令 作用与详细说明
su - 用户名 切换用户。
注意：从 root 切换到普通用户不需要密码；从普通用户切回 root 需要 root 密码。
userdel 用户名 仅删除账号。
userdel -r 用户名 重点：删除用户的同时，连带删除用户的家目录，清理得干干净净。

权限与所有权——Linux 安全的核心基石

多用户操作系统中最核心的问题就是：“怎么保证 A 用户不能删掉 B 用户的文件？” 这全靠 Linux 严密的权限体系

揭秘Linux的文件权限（r, w, x）

我们在终端敲入 ll（即 ls -l），会看到类似 -rw-r–r– 的字符串。它一共分为 10 位：

第 1 位（文件类型）：- 普通文件，d 普通目录，l 快捷方式（软链接）。

第 2-4 位（文件拥有者权限，U）：通常是 root 或创建者。

第 5-7 位（所属组内用户权限，G）：同组用户拥有什么权限。

第 8-10 位（其他用户权限，O）：系统里的其他无关账号有什么权限。

⚠️ 关键区别：文件和目录的权限含义大不同！

权限字符 对文件的意义 对目录的意义
r (读) 可以查看文件内容（如 cat 查看）。 可以列出目录下的文件名（如 ls 查看）。
w (写) 可以修改文件内容（如 vim 修改后保存）。 可以在目录中新建或删除文件。
x (执行) 可以执行该文件（如果是脚本或二进制程序）。 可以进入这个目录（如 cd 进入）。

💡 新手踩坑提示：如果你给一个目录设置了 rwx 但不给目录里面的文件 r 权限，你可以 cd 进去，但是无法 cat 看到里面的文件内容。权限是层层过滤的！

使用chmod修改权限

方式有两种，数字方式（强烈建议记住，日常使用最多）：

r = 4，w = 2，x = 1。

常见的组合：7(4+2+1) = 读+写+执行（满权限），5(4+1) = 读+执行，6(4+2) = 读+写，4 = 只读。

特殊权限与umask

冒险位S(SetUID)：通常出现在 /usr/bin/passwd 上。普通的用户没有权限修改 /etc/shadow 密码文件，但因为 passwd 命令拥有s冒险位权限，普通用户在运行它时，临时拥有了 root 的权限，从而可以修改自己的密码。

粘滞位T(Sticky Bit)：通常出现在 /tmp 目录上。它保证了在这个公共目录里，除了文件主人和 root，其他任何人都不能删除别人的文件。

umask默认权限：新创建的文件为何默认是 644？因为系统默认的最大文件权限是 666，减去 umask 值 022，结果就是 644。新目录默认是777 - 022 = 755

更改文件拥有者

改变文件的所属组。同时修改可以用chown root:root文件

ACL高级控制

如果你只想给某个特定的单个用户（比如刚入职的 user1）分配特定权限，而不想改变整个组的权限怎么办？用 setfacl！

源码包 vs 二进制包

Linux 里的软件包分为源码包和二进制包

防火墙管理（firewalld）

firewalld 是 Linux 的防火墙，默认是关闭的

当你在服务器上启动了一个服务，但在浏览器打不开时，80% 的概率是被防火墙拦截了

查看当前区域规则：firewall-cmd –list-all。

放行服务：firewall-cmd –zone=public –add-service=http。

放行端口（临时）：firewall-cmd –zone=public –add-port=3306/tcp。

放行端口（永久生效）：firewall-cmd –zone=public –add-port=3306/tcp –permanent。配置完永久规则后，必须执行 firewall-cmd –reload 让规则立即生效！

(注：Ubuntu 系统默认使用 ufw 防火墙，用法类似 sudo ufw enable/disable)

top：实时动态显示 CPU、内存占用、负载情况的交互式工具。（按 P 键按 CPU 排序，按 M 键按内存排序）。

htop：top 的增强版，有彩色进度条、鼠标支持，更易用（需 dnf install htop）

如何让任务在后台平稳运行（screen）

screen 是 Linux 的一个终端模拟工具，它可以让任务在服务器上运行，即使你断开 SSH 连接，任务也不会中断

如果你用 SSH 登录服务器，执行了一个要跑 5 个小时的备份脚本，一旦你把本地电脑合上或者网络断了，任务就会立刻中断。这时候必须使用 screen

主机名配置规范

真实的运维环境中，不要用 node1 这种名字，必须遵循 FQDN（完全限定域名） 规范，如 web.lionelhuman.cn。这关系到后续的 DNS 解析和集群通信

临时修改：hostnamectl set-hostname web.itcast.cn

永久修改：修改文件 /etc/hostname 并重启

养成权限思维，绝不滥用 chmod 777：虽然 chmod 777 能解决所有权限问题，但在生产环境这样设置等同于把门大敞开，极其危险。
