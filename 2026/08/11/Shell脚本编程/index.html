Shell基础

Shell与Shell脚本

Shell 是一个命令行解释器，它可以执行命令，并返回结果

Shell 是 Linux 的命令解释器，负责接收并执行用户输入的命令。平时我们在命令行敲入 ls、cd 等命令，就是交互式的执行

Shell 脚本则是非交互式的，把多条命令、语句预先写在一个 .sh 文件里，一次性让系统读取并执行

💡 Shell 的应用场景：

简化运维：将复杂的命令组合打包

日常巡检：监控 CPU、内存、磁盘状态

批量管理：批量创建用户、批量分发免密登录

自动化部署：快速搭建 LNMP、LNMT 等环境

变量的命名与单双引号

变量是存储数据的容器。

命名规则：由字母、数字、下划线组成，不能以数字开头，区分大小写。

单引号与双引号区别：

单引号：强引用，里面的变量原样输出，不解析。

双引号：弱引用，里面的变量会被解析为具体的值。

局部变量与环境变量：使用 export 定义的环境变量可以在子 Shell 中生效。我们常见的 JAVA_HOME、PATH 都是系统环境变量。

环境变量若想每次登录都生效，必须写入配置文件

系统级别放在 /etc/profile 或 /etc/bashrc，用户级别放在 ~/.bash_profile 或 ~/.bashrc

特殊的内置变量

在编写自动化脚本时，以下变量非常重要：

$0：当前脚本的文件名。

$1, $2, …：传递给脚本的第1个、第2个参数。

$#：传递给脚本的参数个数。

$?：极其重要，上一个命令的退出状态。执行成功返回 0，失败返回非 0。这是脚本做判断的根本依据。

$RANDOM：系统内置随机数（0~32767），常用于生成随机密码或抽奖

文本处理三剑客与数据截取

运维时，我们经常需要对日志文件、配置文件进行清洗和截取。以下工具是必须掌握

cut (列截取)：按列提取数据。cut -d’:’ -f1 /etc/passwd 可以快速提取所有用户名。

sort (排序)：默认字符升序，配合 -n 按数字排序，-r 降序。

uniq (去重)：去除连续重复的行，常结合 sort 使用
