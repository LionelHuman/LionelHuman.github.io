Shell基础

Shell与Shell脚本

Shell 是一个命令行解释器，它可以执行命令，并返回结果

Shell 是 Linux 的命令解释器，负责接收并执行用户输入的命令。平时我们在命令行敲入 ls、cd 等命令，就是交互式的执行

Shell 脚本则是非交互式的，把多条命令、语句预先写在一个 .sh 文件里，一次性让系统读取并执行

💡 Shell 的应用场景：

简化运维：将复杂的命令组合打包

日常巡检：监控 CPU、内存、磁盘状态

批量管理：批量创建用户、批量分发免密登录

自动化部署：快速搭建 LNMP、LNMT 等环境

Shell 变量

写脚本时，你经常需要反复使用某个值。比如某个路径、某个用户名、某个 IP 地址。每次都重新输入不仅麻烦，而且一旦要修改，得把所有出现的地方都改一遍

你可以把变量想象成一个”储物盒”——你把数据放进去，贴个标签，以后要用的时候直接喊标签名字就行

变量的三个核心特征：

  • 变量是存储数据的容器

  • 变量中存储的数据是临时的（脚本执行结束就消失）

  • 变量中的数据可以变化（可以重新赋值）

局部变量 vs 环境变量

Shell 中的变量分为两大类：局部变量和环境变量（也叫全局变量）

局部变量

局部变量只能在定义它的那个 Shell 或脚本中使用。离开这个范围就失效了

你在终端敲下这行命令，name 只对当前这个终端窗口有效。再开一个新终端，echo $name 什么都输出不了

环境变量

环境变量是所有 Shell 都有的变量。

环境变量的”势力范围”更大——它不仅在当前 Shell 中有效，还会被传递给所有子进程

什么是”当前 Shell”和”子进程”？

  • 当前 Shell：当前正在执行的 Shell，比如你正在运行一个脚本，或者你正在运行一个命令行。

  • 子进程：当前 Shell 运行一个命令行，这个命令行会创建一个子进程，这个子进程会执行这个命令行。

面试高频题

问：局部变量和环境变量有什么区别？

答：局部变量只能在当前 Shell 或函数中使用，无法传递给子进程；环境变量不仅当前 Shell 可用，还会传递给所有派生的子进程。环境变量需要用 export 声明，且名称通常全大写

问：单引号 vs 双引号

答：单引号内的内容原样输出，双引号内的内容会进行变量替换

使用建议：

  • 纯数字或纯字符串，不加引号也可以

  • 如果字符串中含有变量，用双引号，让变量正常解析

  • 如果确实需要原样输出 $ 符号（比如输出 $PATH 这个文本），用单引号

最稳妥的做法是：大多数情况下用双引号，只在确实需要原样输出时才用单引号

判断语句的三种写法

在 Shell 中，判断条件的写法有三种，它们的本质是一样的，只是在功能和兼容性上略有不同。

写法一：test 命令

这是最原始的写法，test 本身是一个命令，用于评估条件表达式的真假。

写法二：方括号 [ ]（最常用）

这是 test 命令的别名写法，但一定要注意：方括号两边必须各保留一个空格。这是新手最容易犯的错误。

写法三：双括号 [[ ]]（增强版）

双括号是 Bash 的增强特性，支持正则表达式匹配，功能更强大。同样，两边必须保留空格。

核心概念：以上三种写法，判断为真时返回状态码 0，判断为假时返回非 0 值。这个返回值可以通过 $? 查看。

揭秘 RANDOM：Shell 自带的随机数生成器

Bash 中有一个内置变量叫做 $RANDOM。每次引用它，系统都会返回一个 0 到 32767 之间的随机整数。

每次运行结果都不同，这就是”随机”的魅力。

怎么生成指定范围的随机数？

既然 $RANDOM 返回的是 032767，那我要生成 09 之间的随机数，该怎么做？答案是：取模运算（取余数）。

想要的范围 表达式 说明
0~1 $(( RANDOM % 2 )) 除以 2，余数只有 0 或 1
0~2 $(( RANDOM % 3 )) 除以 3，余数只有 0、1、2
0~9 $(( RANDOM % 10 )) 除以 10，余数 0~9
0~100 $(( RANDOM % 101 )) 除以 101，余数 0~100
50~100 $(( RANDOM % 51 + 50 )) 050 加 50，得到 50100
三位数（100~999） $(( RANDOM % 900 + 100 )) 0899 加 100，得到 100999

记忆口诀：$(( RANDOM % 范围 + 起始值 ))

  • 起始值从 0 开始就只写 %
  • 想要 50~100：%51（一共 51 个数），再加 50
