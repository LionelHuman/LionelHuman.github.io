命令速查表

命令 说明
kubectl get pods 列出当前命名空间下的所有 Pod
kubectl get pods -o wide 列出 Pod 并显示更多信息（节点、IP 等）
kubectl get all 列出当前命名空间下所有常见资源（Pod、Service、Deployment 等）
kubectl describe pod <pod-name> 显示 Pod 的详细状态和事件
kubectl logs <pod-name> 查看 Pod 的日志
kubectl logs -f <pod-name> 实时跟踪 Pod 日志（类似 tail -f）
kubectl exec -it <pod-name> -- /bin/sh 进入 Pod 的交互式 shell（若使用 Bash 可改为 /bin/bash）
kubectl port-forward <pod-name> <local-port>:<pod-port> 将本地端口转发到 Pod 端口，用于调试
kubectl create -f <file.yaml> 从 YAML 文件创建资源
kubectl apply -f <file.yaml> 声明式应用 YAML 文件（创建或更新资源）
kubectl delete -f <file.yaml> 从 YAML 文件删除资源
kubectl delete pod <pod-name> 删除指定的 Pod（会被控制器自动重建，除非属于静态 Pod）
kubectl scale deployment <deploy-name> --replicas=<n> 伸缩 Deployment 的副本数
kubectl rollout status deployment <deploy-name> 查看 Deployment 的滚动更新状态
kubectl rollout undo deployment <deploy-name> 回滚 Deployment 到上一个版本
kubectl get services 列出所有 Service
kubectl get deployments 列出所有 Deployment
kubectl get nodes 列出集群所有节点
kubectl get ingress 列出所有 Ingress 规则
kubectl config view 查看当前 kubeconfig 配置内容
kubectl config get-contexts 列出所有可用的上下文
kubectl config use-context <context> 切换当前上下文
kubectl get pods -n <namespace> 指定命名空间查看 Pod
kubectl label pod <pod-name> <key>=<value> 给 Pod 添加或修改标签
kubectl annotate pod <pod-name> <key>=<value> 给 Pod 添加或修改注解
kubectl edit deployment <deploy-name> 直接编辑 Deployment 的配置（会触发滚动更新）
kubectl top nodes 查看节点资源使用情况（需 Metrics Server）
kubectl top pods 查看 Pod 资源使用情况（需 Metrics Server）
