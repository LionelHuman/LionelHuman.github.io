Swift 函数：写代码不是复制粘贴，这几个细节你得搞明白

刚开始写代码的时候，很多人脑子里只有一条主线：从上到下执行

如发现某个操作需要重复写几遍，或者逻辑稍微复杂一点，就开始疯狂地复制粘贴，或者把几十行代码全堆在一个文件里

如此写法代码量小的时候，可读性好，运行也没什么问题，一旦代码膨胀到几百行，想改个逻辑或者排查个 bug，就会痛不欲生

此时就该把代码拆解成一个个独立的“积木块”，而这，正是函数的用武之地

Swift 里的函数，跟其他语言里那种纯粹的 function(a, b) 有点不太一样

它有一套非常有特色的参数标签机制，还有 inout、可变参数、函数类型等一大堆灵活到让人眼花缭乱的特性

函数的定义和调用：从打招呼开始

定义函数用 func 关键字，函数名后面跟一对括号，里面放参数，如果函数有返回值，用 -> 跟上返回类型

很多人刚看到 person: 会觉得多此一举，觉得写个 greet("Anna") 不是更简洁吗？

其实，加上标签之后的函数调用更像是一句自然的英语，读起来非常顺畅。这也是 Swift 的核心理念之一：可读性优先。

避坑指南：
调用函数时，参数的顺序必须和定义时的顺序保持一致。你不能写成 greet("Anna", age: 25) 去调用 greet(age: 25, person: "Anna")，编译器会直接报错。

参数与返回值：灵活多变的组合

Swift 的函数非常灵活，你可以没有参数，可以没有返回值，也可以返回多个值。

无参数函数

定义一个函数，它不接受任何外部输入，但每次调用时都会返回一个固定的字符串消息

Swift 中，即使函数不接受任何参数，定义和调用时也必须使用空括号 ()

定义时：函数名后必须有空括号

注意函数名 sayHelloWorld 后面的 ()。即使函数不需要任何参数，这对空括号也是必需的
如果不加括号写成 func sayHelloWorld -> String，Swift 编译器会认为语法错误，或者把它理解为变量声明而非函数定义
这对空括号就像是函数的“身份证”，告诉编译器这是一个可执行的代码块，而不是一个属性或变量

调用时：也必须带上空括号

无返回值函数

Swift 中，定义一个函数时，并不强制要求必须有返回值

如果一个函数只是为了执行某些操作，比如打印日志、修改全局变量等，我们不需要写返回箭头（->）和返回类型

注意，这里没有写 ->，因为函数不需要返回任何值
💡 底层原理：其实它也是“有”返回值的，严格来说，即使没有定义返回值，这个函数仍然返回了一个值
Swift 中，没有定义返回类型的函数，实际上会隐式返回 Void 类型的特殊值
Void 在 Swift 中是一个空的元组，写作 ()。
greet(person:) 函数在编译器眼中，等同于
func greet(person: String) -> Void 或 func greet(person: String) -> ()只是 Swift 帮我们省略了这些冗余的语法

调用时忽略返回值

如果一个函数定义了返回值，我们在调用它时，并不是必须使用这个返回值。Swift 允许我们安全地忽略它

  1. printAndCount 打印字符串并返回其字符数（Int 类型）。

  2. printWithoutCounting 调用了第一个函数，但通过 let _ = 语法，显式地告诉编译器：“我知道它有返回值，但我并不关心，我要丢弃它”。

  3. 当 printWithoutCounting 被调用时，消息依然会被打印（副作用），但返回值被丢弃了

小贴士：如果不需要使用返回值，直接调用 printAndCount(string: “hello”) 也是合法的，Swift 不会警告你未使用返回值。使用 let _ = 仅仅是一种更具可读性的显式声明方式

编译器的严格底线：必须有返回

具有定义返回类型的函数不能允许控制从函数底部脱落而不返回值，尝试这样做将导致编译时错误

意味着，只要你声明了 -> Int（或其他类型），你就必须保证函数的所有执行路径最终都会 return 一个 Int

函数可以没有返回值，实际返回的是空元组 Void 即 ()
调用有返回值的函数时，可以使用 _ 来忽略返回结果
只要声明了返回类型，函数就必须在所有路径上返回对应类型的值，绝不允许从底部“滑落”

隐式返回

隐式返回是 Swift 5.1 引入的一项非常优雅的语法糖

日常开发中，我们经常会遇到一些逻辑非常简单的函数，它们仅仅是计算并返回一个值

为了代码的简洁性，Swift 提供了一种名为隐式返回（Implicit Returns）的语法糖

如果函数体只有一行表达式，可以省略 return 关键字：

greeting(for:) 函数中，整个函数体只有一行表达式 “Hello, “ + person + “!”
因为返回值类型已经声明为 String，编译器非常聪明地知道这行代码的结果就是返回值，因此我们完全不需要写 return

💡 延伸：属性获取器（Computed Properties）

隐式返回的规则同样适用于只读计算属性 getter

避坑指南：隐式返回的严格限制

  1. 必须有值可返回

作为隐式返回值编写的代码必须产生一个值。并且，这个值的类型必须与函数声明的返回类型匹配

❌ 错误示例：

print(13) 仅仅是执行了一个打印动作，它本身返回的是 Void（即 ()）。所以它不能作为隐式返回值提供给声明了 -> String 的函数

  1. 特例：使用 Never 类型的函数

虽然 print(13) 不能作为隐式返回值，但我们可以使用一个永远不会正常返回的函数（返回类型为 Never）作为隐式返回值

✅ 有效示例：

fatalError(“Oh no!”) 会直接导致程序崩溃并终止运行，它的返回类型是 Never

因为 Swift 编译器知道这段代码永远不会执行到“返回”那一步（隐式返回不会发生），所以允许这种写法

什么时候该用隐式返回？

推荐使用：当函数体只有极其简单的一行表达式时，例如简单的字符串拼接、数学运算、返回某个属性
这能大幅提升代码的阅读体验，减少视觉噪音（视觉上类似于很多函数式语言）

不推荐使用：如果函数体包含多行代码、复杂的逻辑判断 if/else、guard、或者带有副作用如网络请求、数据写入
在这些情况下，显式书写 return 会让代码意图更清晰，避免团队成员阅读时产生歧义

单表达式函数可以使用隐式返回，省略 return 关键字。
这一规则同样适用于只读计算属性（getter）。
隐式返回要求表达式的类型必须与函数返回类型匹配（print() 返回 Void，因此不能用于隐式返回）。
返回类型为 Never 的函数（如 fatalError）是个例外，可以用作隐式返回，因为编译器知道程序会在此中断。

  • 参数名：在函数体内部使用
  • 默认情况：如果不做特殊处理，参数名称默认作为参数标签

可变参数与 inout 参数：进阶玩法

可变参数允许你传入零个或多个同一类型的值。写法是在类型后面加 ...。传入的值在函数体内会作为适当类型的数组提供

在函数体内部，numbers 被当成 [Double] 数组使用。

规则限制：

  • 一个函数可以有多个可变参数。

  • 可变参数之后的第一个参数必须有一个参数标签。参数标签明确了哪些参数传递给可变参数，哪些参数传递给可变参数之后的参数

输入输出参数 inout

函数参数默认是常量，函数体内改不了它的值。如果你确实需要修改传入的变量，并且希望修改在函数结束后依然生效，就需要用 inout 关键字。

  1. 语法与调用

使用 inout 关键字在参数类型之前进行声明。调用时，必须在变量名称前加上 & 符号（ampersand），表明它可以被函数修改

注意调用时变量前面要加 &。

  1. 避坑指南

只能传递变量给 inout 参数，不能传递常量或字面值，因为常量和字面值无法修改

inout 参数不能有默认值。

可变参数不能标记为 inout

  1. 本质区别

输入输出参数与从函数中返回值不同，swapTwoInts 示例没有定义返回类型或返回值，但它仍然修改了 someInt 和 anotherInt 的值
输入输出参数是函数在其函数体范围之外产生效果的替代方式，类似于其他语言中的引用传递

总结
Swift 的参数设计是其 API 设计指南的核心体现：
参数标签让调用端代码如自然语言般优雅；参数名称让实现端逻辑清晰。
默认参数减少了重载函数的冗余。
可变参数优雅处理同类型不定长入参。
输入输出参数（inout）打破了值类型常量传递的限制，配合 & 符号，实现了外部变量的原地修改

嵌套函数

可以在一个函数内部定义另一个函数。默认情况下，嵌套函数对外部不可见，但可以被外部函数调用和返回

stepForward 和 stepBackward 被完美地封装在了 chooseStepFunction 内部，不仅避免了全局命名空间的污染，还让代码的组织结构更加清晰

避坑指南：
函数类型必须完全匹配。如果你把 (Int, Int) -> Int 类型的函数赋值给 (Int) -> Int 的变量，编译器会直接报错，因为参数个数不同，类型系统不兼容。

总结
函数类型是 Swift 语言的一项核心特性，它赋予了函数极高的灵活性：

赋值与传递：函数可以像变量一样被赋值和传递。

高阶函数：函数可以作为参数传入另一个函数，让调用者决定部分实现逻辑。

函数工厂：函数可以作为返回值，根据条件动态生成特定的执行逻辑。

嵌套函数：在函数内部定义函数，实现局部封装，并在合适的时机对外暴露。
