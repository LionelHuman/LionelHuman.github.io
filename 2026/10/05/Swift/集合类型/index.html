Swift 集合类型：数组、集合和字典，到底该选哪个？

很多人刚学完基础类型和字符串，准备开始写点“有逻辑”的代码时，都会遇到一个很现实的问题：我有一堆数据，该怎么存？

如果你从别的语言转过来，可能会本能地想到数组，然后把什么东西都往数组里塞

结果就是：写一个查找功能，需要写 for 循环挨个比对；想去重，还得手写一套复杂的算法

Swift 里，除了数组，还有集合和字典，它们各自有非常明确的适用场景，用错了类型，代码又长又慢；用对了，一行代码就能解决

可变性：别让编译器教你做人

不管你用哪种集合，第一件事就是决定用 let 还是 var。

如果你用 var 创建，集合是可变的，你可以随意添加、删除、修改里面的元素

如果你用 let，集合就是不可变的，大小和内容都不能变。

避坑指南：
很多人一上来就习惯性写 var，觉得以后可能会改。其实我的建议恰恰相反：先写 let，如果编译器报错告诉你这里必须修改，再改成 var。 这不仅仅是个习惯，它能让编译器帮你做更多的优化，也能让读代码的人一眼看出“这个数据是不会变的”。

遍历数组

避坑指南：数组越界与索引陷阱
Swift 的数组是从 0 开始索引的
如果你有 3 个元素，最大合法索引是 2
试图访问 shoppingList[3] 或者 shoppingList[shoppingList.count] 会直接导致程序崩溃（运行时错误）
如果你在遍历时删除元素，或者使用 remove(at:) 后继续用旧的索引去访问，极大概率会翻车
删除元素后，后面的元素会自动填补空隙，索引会发生变化

Swift 集合常用方法速查表

集合是无序且元素唯一的，因此它的独门绝技集中在“去重”、“集合数学运算”以及“集合关系判断”上。

分类 方法/属性 描述 示例/返回值 避坑与备注
基础 count 获取元素数量 set.count -> Int 无
基础 isEmpty 判断是否为空 set.isEmpty -> Bool 无
增 insert(_:) 插入元素 set.insert("Rock") 插入已存在的元素不会报错，也不会重复添加
删 remove(_:) 删除元素并返回 set.remove("Rock") -> String? 如果元素不存在，返回 nil
删 removeAll() 清空集合 set.removeAll() 无
查 contains(_:) 判断是否包含某元素 set.contains("Jazz") -> Bool 比数组查找效率高得多（O(1)）
运算 union(_:) 并集 a.union(b) 返回包含 a 和 b 所有元素的新集合
运算 intersection(_:) 交集 a.intersection(b) 返回同时在 a 和 b 中的元素
运算 subtracting(_:) 差集 a.subtracting(b) 返回在 a 中但不在 b 中的元素
运算 symmetricDifference(_:) 对称差集 a.symmetricDifference(b) 返回在 a 或 b 中，但不同时存在的元素
关系 isSubset(of:) 判断是否为子集 small.isSubset(of: big) -> Bool 包含相等的情况
关系 isSuperset(of:) 判断是否为超集 big.isSuperset(of: small) -> Bool 包含相等的情况
关系 isDisjoint(with:) 判断是否无交集 a.isDisjoint(with: b) -> Bool 两个集合没有共同元素时返回 true
排序 sorted() 转为排序后的数组 set.sorted() -> [String] 集合本身无序，需要顺序时必须用此方法转成数组

Swift 字典常用方法速查表

字典存储**键值对（Key-Value）**关联，键必须唯一且遵守 Hashable 协议。

分类 方法/属性 描述 示例/返回值 避坑与备注
基础 count 获取键值对数量 dict.count -> Int 无
基础 isEmpty 判断是否为空 dict.isEmpty -> Bool 无
增改 dict[key] = value 添加或修改键值 dict["Math"] = 95 如果 key 已存在则覆盖，不存在则新增
增改 updateValue(_:forKey:) 更新并返回旧值 dict.updateValue(100, forKey: "Math") -> Int? 旧值存在则返回旧值，不存在返回 nil
删 dict[key] = nil 通过赋 nil 删除键值对 dict["Math"] = nil 无
删 removeValue(forKey:) 删除并返回被删的值 dict.removeValue(forKey: "Math") -> Int? 原 key 不存在时返回 nil
删 removeAll() 清空字典 dict.removeAll() 无
查 dict[key] 读取键对应的值 dict["Math"] -> Int? **返回可选类型！**必须用 if let 或 ?? 处理
查 .keys / .values 获取所有键/值的集合 dict.keys -> Dictionary.Keys 类型不是数组，若需数组需用 [String](dict.keys) 转换
合并 merge(_:uniquingKeysWith:) 合并两个字典 dict1.merge(dict2) { (old, new) in new } 闭包用来决定遇到重复 key 时保留哪个值
遍历 for (k, v) in dict 遍历键值对 for (code, name) in airports 字典是无序的，如需顺序遍历需先 sorted()

到底该选哪个？

最后给你一张简单的决策图：

  • 如果你需要按顺序存放东西，而且可能有重复项（比如待办事项列表），用数组。
  • 如果你只关心是否存在，需要去重，或者需要做集合运算（比如标签、好友列表），用集合。
  • 如果你需要通过一个标识符去查找对应的值（比如用户 ID 找用户信息），用字典。
